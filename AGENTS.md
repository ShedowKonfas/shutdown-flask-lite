# AGENTS.md

Назначение: Flask-пульт для Windows — выключить или перезагрузить ПК из браузера.
## Карта файлов

| Файл | Роль |
|---|---|
| `main.pyw` | приложение, HTML, маршруты `/`, `/shutdown`, `/reboot` |
| `start.cmd` | бесконсольный запуск через `pythonw` |
| `requirements.txt` | единственная зависимость — Flask |
## Запуск и проверка

`python -m venv venv` → `venv\Scripts\pip install -r requirements.txt` → `start.cmd`.
Проверка только главной страницы: `venv\Scripts\python -c "import runpy; print(runpy.run_path('main.pyw')['app'].test_client().get('/').status_code)"` → `200`.
Тестовой команды нет; не выдумывай тесты без запроса пользователя.
## Соглашения

- Windows only: код использует `shutdown.exe`; интерфейс — на русском.
- `requirements.txt` остаётся минимальным; авторизацию не добавляй «заодно».
## Подводные камни

- `/shutdown` и `/reboot` реально выключают ПК — при проверке не вызывай их.
- `main.pyw` не импортируется через `import main`, используй `runpy.run_path`.
- Авторизации нет, порт 5000 нельзя пробрасывать наружу.
