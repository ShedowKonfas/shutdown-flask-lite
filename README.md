# Пульт питания ПК (shutdown-flask-lite)

Мини-сервер на Flask для Windows с двумя действиями: выключить и перезагрузить ПК. Запускается без консоли, панель открывается с другого устройства в той же сети.

## Быстрый старт

```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```

`start.cmd` переходит в папку проекта и запускает `main.pyw` через `venv\Scripts\pythonw.exe`. Если `venv` нет, используется системный `pythonw`.

## Доступ

```
http://127.0.0.1:5000          — с самого ПК
http://<ip вашего ПК>:5000     — из локальной сети
```

## Маршруты

| URL | Действие |
|---|---|
| `/` | панель с двумя кнопками |
| `/shutdown` | `shutdown /s /t 2` |
| `/reboot` | `shutdown /r /t 2` |

## Структура

| Файл | Роль |
|---|---|
| `main.pyw` | Flask-приложение, HTML-шаблон и маршруты |
| `start.cmd` | бесконсольный запуск |
| `requirements.txt` | зависимости (только Flask) |
| `README.md`, `AGENTS.md` | документация |

## Проверка без выключения ПК

Проверяем только главную страницу:

```bat
venv\Scripts\python -c "import runpy; print(runpy.run_path('main.pyw')['app'].test_client().get('/').status_code)"
```

Ожидаемый результат: `200`. Не вызывайте `/shutdown` и `/reboot` при проверке — команды реально выключат или перезагрузят машину.

## Безопасность

Авторизации нет: любой в той же сети может выключить ПК. Не пробрасывайте порт 5000 наружу.

## Ветки в исходном репозитории

- `main` — полная версия с Глашей и удалённой клавиатурой;
- `shutdown-reboot-only` — только питание ПК.
