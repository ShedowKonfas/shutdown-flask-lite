# 🎛️ Пульт управления ПК

Небольшой веб-пульт на Flask для Windows: выключает и перезагружает компьютер, запускает голосового ассистента и удалённую клавиатуру прямо со телефона в локальной сети.

## ✨ Что умеет

| Действие | Кнопка | Что происходит |
|---|---|---|
| Выключение | 🔴 Выключить ПК | `shutdown /s /t 2` |
| Перезагрузка | 🔁 Перезагрузить ПК | `shutdown /r /t 2` |
| Голосовой ассистент | 🖲️ Запустить Глашу | открывает `glados.cmd.lnk` |
| Удалённый ввод | ⌨️ Клавиатура | открывает `wifi-kb.cmd.lnk` |
| Стоп | 🚨 Остановить скрипт | заготовка под остановку сервера |

Интерфейс — тёмная адаптивная панель: сетка кнопок, подсветка фокуса, состояния наведения и упрощённая раскладка для узких экранов.

## 🚀 Запуск

Двойной клик по **`start.cmd`** — сервер поднимется без консоли и без окна терминала.

```bat
start.cmd
```

Скрипт сам:

1. переходит в папку проекта (`cd /d "%~dp0"` — важно для `.lnk`-ярлыков);
2. берёт `venv\Scripts\pythonw.exe`, если venv есть, иначе системный `pythonw`;
3. запускает `main.pyw`.

При первом запуске на чистой машине:

```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```

## 🌐 Доступ

Сервер слушает `0.0.0.0:5000`, поэтому открыть панель можно с любого устройства в сети:

```
http://127.0.0.1:5000          — с самого ПК
http://192.168.3.76:5000       — из локальной сети
```

IP-адрес можно узнать командой `ipconfig`.

Остановить сервер можно через диспетчер задач (процесс `pythonw.exe`) или командой:

```powershell
Get-NetTCPConnection -LocalPort 5000 -State Listen |
  ForEach-Object { Stop-Process -Id $_.OwningProcess }
```

## 🗺️ Маршруты

| URL | Действие |
|---|---|
| `/` | панель управления |
| `/shutdown` | выключить ПК |
| `/reboot` | перезагрузить ПК |
| `/glados` | запустить Глашу |
| `/keyboard` | запустить удалённую клавиатуру |
| `/stop` | заглушка остановки |

## 🔒 Безопасность

У приложения **нет авторизации**, а команды выключения и перезагрузки доступны всем, кто попадёт в ту же сеть. Держите сервер в доверенной домашней сети и не пробрасывайте порт 5000 наружу.

## 🛠️ Известные нюансы

- `/stop` возвращает ответ раньше, чем вызывается `sys.exit()` — процесс остаётся живым.
- `subprocess.run('shutdown /s /t 2')` не проверяет код возврата: если у пользователя нет прав на завершение работы, ошибка останется незамеченной.
- Приложение рассчитано только на Windows (`os.startfile`, `shutdown.exe`).
